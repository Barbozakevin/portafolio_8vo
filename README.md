# Kevin Barboza | Portafolio Personal

Portfolio personal desarrollado para presentar mi perfil profesional, experiencia académica, habilidades técnicas y proyectos destacados en el área de ingeniería de software. Este proyecto busca reflejar una identidad visual moderna, con un enfoque en diseño, usabilidad y navegación intuitiva.

## Descripción del proyecto

Este portafolio funciona como una landing page dinámica y moderna, donde se muestran de forma clara y organizada las siguientes secciones:

- Presentación personal y profesional.
- Formación e intereses dentro de la ingeniería de software.
- Habilidades y tecnologías aprendidas.
- Proyectos académicos y tecnológicos destacados.
- Diseño visual del sistema de componentes.
- Formulario de contacto con validación.

La intención principal es crear una presencia digital sólida que permita mostrar mi trabajo, mi crecimiento académico y mis capacidades técnicas a posibles colaboradores, instituciones o clientes.

## Objetivo

Diseñar y desarrollar una web portfolio personal que combine un buen diseño visual con una experiencia de usuario fluida, facilitando la presentación de mi perfil como estudiante de Ingeniería de Software.

## Características principales

- Pantalla de bienvenida inicial con animación y bloqueo temporal de la página.
- Navegación principal con menú responsive.
- Cambio de tema claro y oscuro con almacenamiento local.
- Filtros interactivos para proyectos por categoría.
- Modales con información detallada de cada proyecto.
- Formulario de contacto con validación JavaScript.
- Botón para volver al inicio.
- Navegación suave entre secciones.
- Diseño visual reutilizable con sistema de colores, tipografía y espaciado.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Diseño responsive
- Accesibilidad y usabilidad básica

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en tu editor.
3. Ejecuta el archivo `index.html` directamente en el navegador.

También puedes levantarlo con un servidor local:

```bash
python -m http.server 8000
```

Luego accede en tu navegador a:

```bash
http://localhost:8000
```

## Personalización

Los archivos principales para editar el contenido y estilo del portafolio son:

- `index.html`: estructura, contenido y secciones principales.
- `root.css`: variables del sistema visual (colores, espaciado, fuente, sombras).
- `style.css`: estilos globales y diseño del sitio.
- `script.js`: interactividad, filtros, modal, validación del formulario y tema.
